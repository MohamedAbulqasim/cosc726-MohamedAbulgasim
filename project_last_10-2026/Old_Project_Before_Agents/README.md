# المشروع الأصلي لتشخيص السكري (قبل إضافة الوكلاء الذكيين)
## Original Diabetes Prediction Project (Before Intelligent Agents)

### 📌 نبذة عن المشروع الأصلي
هذا المجلد يحتوي على النسخة الأصلية الكاملة لمشروع تشخيص السكري كما كانت قبل الترقية المعمارية وإضافة منظومة الوكلاء الذكيين المتعددين (Agentic AI).

### 🛠️ المكونات التقنية للمشروع القديم:
1. **واجهة المستخدم:**
   - تطبيق سطح مكتب كلاسيكي مبني باستخدام مكتبة **Tkinter** الرسومية (`diabetes_predict.py`).
2. **نموذج الذكاء الاصطناعي:**
   - نموذج تصنيف تقليدي أحادي غير معاير مبني باستخدام خوارزمية **Random Forest Classifier** (`diabetes_model.pkl`).
3. **قاعدة البيانات:**
   - مجموعة بيانات سكري الهنود الحمر **Pima Indians Diabetes Database** (`diabetes_data.csv`).
4. **الحزم والملفات القابلة للتشغيل:**
   - ملف مواصفات التجميع **PyInstaller** (`diabetes_predict.spec`).
   - تم نقل الملف التنفيذي المستقل (`dist/`) وملفات البناء المؤقتة (`build/`) إلى مجلد الأرشيف الخارجي `../Old_Project_Archive/` لتخفيض حجم المجلد من 252 ميجابايت إلى 7.58 ميجابايت فقط.
5. **العرض التقديمي والمستندات الأصلية:**
   - العرض التقديمي بصيغة باوربوينت (`project presention.pptx`).
   - العرض التقديمي بصيغة PDF (`project presention.pdf`).
   - الملحقات الإضافية والتقارير الأصلية الفريدة في مجلد (`الملحقات_الاضافية_PDF/`).

---

### 🚀 كيفية تشغيل المشروع القديم:

#### 1. عبر سطر الأوامر (Python):
```bash
python diabetes_predict.py
```

#### 2. عبر ملف التشغيل السريع:
قم بالنقر المزدوج على:
```
run_desktop_app.bat
```

#### 3. تشغيل الملف التنفيذي المباشر (Standalone EXE):
يمكنك تشغيل البرنامج مباشرة بدون الحاجة لتثبيت بايثون من مجلد الأرشيف:
```
../Old_Project_Archive/run_standalone_exe.bat
أو: ../Old_Project_Archive/dist/diabetes_predict.exe
```

### ⚠️ أوجه القصور التي استدعت التحول إلى نظام الوكلاء (Agentic AI):
- **غياب التعليل الطبي:** النموذج القديم كان يكتفي بإخراج رقم احتمالي وتصنيف (مصاب / سليم) دون تقديم تفسير سريري للأسباب.
- **احتماليات غير معايرة إحصائياً:** النسب الناتجة عن Random Forest المباشر لم تكن تعكس الاحتمالية السريرية الحقيقية (Calibrated Probability).
- **غياب فريق استشاري:** عدم وجود وكلاء مخصصين للفرز الأولي، التحقق من البيانات، التغذية ونمط الحياة، واعتراض الحالات الطارئة.
