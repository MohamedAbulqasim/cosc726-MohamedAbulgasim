## 🌟 نظرة عامة والسياق الأكاديمي
تم تحويل المشروع بالكامل من نظام تنبؤ فردي بسيط (معتمد على Tkinter ونموذج Random Forest غير معاير) إلى **نظام ذكاء اصطناعي سريري متعدد الوكلاء (Agentic Multi-Agent System)** مدعوم بنماذج اللغة الكبيرة (**LLM**) وبوابات جودة وقيود سريرية صارمة (**Clinical Quality Gates**)، مع واجهة ويب تفاعلية حديثة (**Streamlit**) وتوليد تقارير طبية ومقترحات بحثية رسمية بصيغة Word (.docx) باللغتين العربية والإنجليزية.

> **🎓 توثيق الأصل الأكاديمي والتحول المعماري بين الفصلين:**  
> يُعد هذا النظام نقلة معمارية نوعية لمشروع مقرر **"تعلم الآلة (Machine Learning)"** الذي أنجزه الباحث خلال **الفصل الدراسي السابق** (والمحفوظ في المجلد `../Old_Project_Before_Agents/`). في ذلك المقرر السابق، كان التركيز منصباً على التدريب الإحصائي لخوارزميات التصنيف الكلاسيكية وواجهة Tkinter تقليدية للتنبؤ الثنائي (0 أو 1).  
> وفي هذا الفصل الدراسي الحالي، وضمن متطلبات مساق **"الذكاء الاصطناعي القائم على الوكلاء (COSC726: Agentic Artificial Intelligence)"** بإشراف الدكتور فخرالدين سعيد، تم تطوير المشروع جذرياً ليتحول من نموذج رياضي فردي معزول إلى منظومة سريرية متكاملة تحاكي فريقاً استشارياً طبياً من 5 وكلاء أذكياء تضمن المعايرة الإحصائية، التعليل المسبب وفق إرشادات الجمعية الأمريكية للسكري (ADA 2024/2026)، والاعتراض الفوري للطوارئ.

## 🚀 كيفية تشغيل المشروع

### 1. تشغيل الواجهة التفاعلية (Streamlit):
من المجلد الرئيسي `d:\111\diabetes_predict`، يمكنك تشغيل الواجهة بأي من الطرق الثلاث التالية:

**الطريقة الأولى (موصى بها ومضمونة):**
```bash
python -m streamlit run app.py
```

**الطريقة الثانية (عبر ملف التشغيل السريع المباشر في ويندوز):**
اضغط نقراً مزدوجاً على الملف:
```bash
run_app.bat
```

**الطريقة الثالثة (عبر أداة التحكم المركزية):**
```bash
python run_system.py --ui
```
ستفتح الواجهة التفاعلية مباشرة في المتصفح وتتضمن:
- اختيار اللغة (عربي RTL أو إنجليزي LTR).
- 4 حالات سريرية تجريبية مسبقة بنقرة واحدة (سليمة، ما قبل السكري، إصابة متقدمة، طوارئ حرجة).
- متتبع حي لخط أنابيب الوكلاء الخمسة وبوابات الجودة.
- شاشات بيانية وتحليلات دقيقة مع زر لتحميل تقرير Word مخصص للمريض مباشرة.

---

### 2. التحقق من مراحل المشروع:
يمكنك تشغيل والتحقق من أي مرحلة على حدة:
```bash
python run_system.py --phase 1    # التحقق من المرحلة 1 (البيانات والنمذجة والمعايرة)
python run_system.py --phase 2    # التحقق من المرحلة 2 (الوكلاء المتعددين والذكاء الاصطناعي)
python run_system.py --phase 3    # التحقق من المرحلة 3 (الواجهة التفاعلية وتقارير المرضى)
python run_system.py --phase 4    # التحقق من المرحلة 4 (الاختبارات الشاملة والقياس المعياري)
python run_system.py --phase all  # التحقق من كافة المراحل الأربع دفعة واحدة
```

---

### 3. إعادة توليد كافة تقارير الوورد والمقترحات البحثية:
```bash
python run_system.py --generate-all-reports
```
